# 英語物語 対戦デッキ自動推薦アプリ

`Book1.xlsx`の収録キャラから条件に合う順番付き5体デッキを生成し、最低保証ダメージ・配置・スキル接続・フェーズ式対戦再現から順位付けするブラウザアプリです。

## 収録データ

`Book1.xlsx`の20シートから2,217行を読み取り、完全一致1件のみを統合した2,216体を収録しています。

- A/B列の背景色から火・水・風・火水・火風・水風・全の7属性を復元
- 属性縛りは火・水・風の3色から選び、選択色を1つでも含むキャラを対象にする
- 限界突破後のHP・Powerを優先し、空欄なら基本値を使用
- リーダースキルは評価対象外
- ゆるスキルの種別・倍率・継続ターン・回数を構造化
- 同名・同ステータスでも属性またはスキルが異なれば別キャラ
- 「対戦」シート218行目の右側に入ったキャラも復元

## 使い方

1. `index.html`をブラウザで開きます。
2. コスト・属性・必須キャラなどを入力します。
3. 「デッキを探索」を押します。
4. 推薦結果の「採用理由・対戦処理・弱点を見る」から、スキル使用・温存、対象、ダメージ、蘇生、交代を確認します。

別データを試す場合は「JSONを読み込む」からキャラクターデータを選択できます。「収録データへ戻す」で`Book1.xlsx`由来のデータへ戻ります。

## 手入力キャラの追加

対戦デッキタブの「＋ キャラを追加」では、無凸Lv1のHP・Powerと育成状態を入力します。無凸LvMAXはLv1の2倍とし、完凸LvMAXはレア度別の到達Lv（例外は個別入力値）から算出し、対戦デッキ探索・キャラ検索・最軽装で共通利用します。スキル詳細では倍率・ヒット数・継続ターン・効果量・対象・味方／敵属性条件・属性変更先を指定でき、短縮と遅延も入力できます。追加したキャラには自動IDが付き、データはこのブラウザに保存されます。複数の独立効果など、フォームで表せない特殊スキルはJSON読み込みを使用してください。詳しくは [docs/character-editor.md](docs/character-editor.md) を参照してください。

## キャラ検索タブ

「キャラ検索」タブでは、名前・ID・属性・スキル・地域・レアリティをキーワードで横断検索できます。複数の言葉を空白で並べると、すべてに合うキャラだけを表示します。

- 火 全体攻撃
- 水 回復
- かばう
- 関東 R

名前の軽い誤字にも対応し、低コストや高火力は候補の表示順へ反映します。キャラIDのコピー、対戦必須キャラ、最軽装候補への追加もできます。JSONデータを読み込むと検索対象も同時に更新されます。詳細は [docs/character-search.md](docs/character-search.md) を参照してください。
## 最軽装タブ

「最軽装」タブでは、限定イベントの固定敵列に対して三冠できる5体デッキを完全探索します。指定コストを入力した場合はその総使用コストだけを調べ、空欄なら低い到達可能値から最大指定コストまで順番に調べます。三冠デッキを1件発見した時点で探索を終了し、回答・5人それぞれのターゲット・スキルを含む推奨プレイ手順を表示します。空欄時は、先に低いコスト帯をすべて調べるため、発見コストが厳密な最小値になります。

- 候補圧縮・ビーム幅・試行上限を使用しない
- 全デッキ組合せと全配置を探索
- スキル温存、同分類内の発動順、正答・半誤答、ターンごとの手動標的を探索
- 同一の戦闘状態だけをメモ化して重複探索を省略
- 松は完凸Lv最大、竹は無凸Lv最大、梅は無凸Lv最大の半分
- 複数ターン回復と、幽霊の半減攻撃を再現
- 同コスト時の公式順位は実時間なので、本ツールでは順位付けしない

味方候補を入力した場合、その候補内での完全探索です。空欄なら属性・レアリティ・所持条件に合う収録キャラを全員調べますが、候補数によっては非常に長時間かかります。詳細は [docs/lightest.md](docs/lightest.md) を参照してください。

## ダメージ計算

最低保証ダメージは`floor(Power × スキル倍率 × 攻撃補正 × 自力 × Excellent × 問題難度 × 属性 × イベント × 特別ルール × 最低乱数 × 対戦固定係数 × 生存 × 防御)`で計算します。

- 標準値は自力`1.2`、Excellent`1.2`、難関`1.8`、最低乱数`0.9`、対戦固定係数`0.75`
- 属性倍率は有利`1`、同属性`2/3`、不利`1/3`
- 複属性は攻撃属性と防御属性の全組み合わせを平均
- 白属性は火・水・風の三属性として扱うため常に`2/3`
- 生存中は経過ターンごとに攻撃力を`1.3倍`し、交代時にリセット
- 攻撃バフは倍率を乗算
- 防御効果は軽減率が高い順に並べ、2個目以降を`3/5`、`3/7`、`3/9`…へ減衰
- イベントボーナス対象は`eventBonus: true`で`1.5倍`、特別ルール倍率は`damage.specialAttackMultiplier`で設定

## 対戦再現

- 処理順をスキル選択、属性変更、回復、攻撃強化、防御、攻撃、蘇生、交代・幽霊化へ分離
- 両チームの攻撃者を攻撃フェーズ開始時に確定し、途中で倒されても攻撃
- 死亡直後には交代せず、蘇生判定後に控えへ交代
- 同じキャラの蘇生は1回まで
- 回復後HPは最大HPの200%まで
- 控えがない場合はPower 1000・全属性・生存補正なしの幽霊になり、防御・かばうを無視
- 全体攻撃がかばわれた場合は、かばう役へ1体分を当てて終了
- 短縮・遅延スキルの効果は無視するが、所持キャラ自体は通常どおり候補へ含める
- 初手はスキルターン不問。2〜5枠目は想定登場ターン（枠番号−1）またはその+1のスキルターンだけ許可
- 標的は残数平準化・撃破確定・発動直前スキルの3方針を盤面ごとに切り替え、環境評価では推定高火力順に攻撃
- 標準では代表味方4人・敵5人を使い、高耐久・標準・低耐久の3シナリオを最大8ターン評価

対戦ログは、代表値を使った推薦理由の説明です。実際の敵デッキを入力した勝率計算ではありません。同時攻撃の厳密な内部順序、連続攻撃で撃破した後の再標的、端数処理は引き続き実機照合が必要です。

## 開発

- `npm test`: 純粋関数・対戦フェーズ・収録データ・探索条件のテスト
- `npm run build`: CSS・JavaScript・2,216体のデータを含む単一`index.html`を生成
- `python scripts/convert_book1_v2.py Book1.xlsx src/data/workbook-characters.js`: Excelデータを再生成

## キャラクター先行評価

旧v1の単純加重点は最終優先度に使用しません。現在は多数の実盤面で同枠敵撃破率・味方維持率・実スキル発動率を測る環境対処評価v3を使用します。詳細は [docs/environment-rating.md](docs/environment-rating.md) を参照してください。

`npm run rate:environment` で全3色・2枠目・総コスト150の環境評価表を生成できます。`npm run check:readiness -- --count=600` では、既存レポートの環境を使って2枠目の登場ターン・方針別発動可能率だけを再計測できます。旧v1は比較検証用として `npm run rate:characters` に残しています。

## 縛り別メタ環境評価

属性・総コスト上限・枠ごとに、戦闘順位と所持率から予測環境を作り直して最終勝率を評価します。単独条件は `npm run rate:metagame`、複数条件の反復評価は `npm run rate:metagame:grid` を使用します。評価基準と引数は [docs/metagame-rating.md](docs/metagame-rating.md) を参照してください。

## 調査済み環境シミュレーター

画面上部の「調査済み環境から、最高勝率の5体を探す」では、メタ環境評価が2巡・5枠とも完了した属性・コスト縛りだけを選択できます。

- 各枠の詳細評価済み候補から、総コスト・同一ID禁止・伝説1体までの条件で5体デッキを生成します。
- 上位候補を30種類の予測環境へ再投入し、完成デッキ単位の予測勝率を比較します。
- 引き分けは0.5勝、12ターンで未決着の場合は残りキャラ数と残HPから勝利見込みを算出します。
- 評価完了済みの縛りを取り込むには npm run build を実行します。
