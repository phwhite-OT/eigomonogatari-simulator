# 環境対処評価 v3

旧キャラクター先行評価v1の単純な攻撃・耐久・スキル加重平均は、最終的な優先度には使用しない。

## 評価対象

- 縛りと枠に入るキャラクターを候補にする。
- 総コスト内で残り4枠を重複なしで完成できるキャラクターだけを残す。
- 短縮・遅延はスキルを発動しないが、通常攻撃とHPを持つキャラクターとして残す。

## 環境の生成

1. 実キャラクターで5対5の初手盤面を多数作る。
2. 初手候補を各盤面へ1体ずつ差し替え、1ターン後の交代数を測る。
3. 攻撃・防御・盤面結果の上位を、予測初手環境として重み付きで残す。
4. その初手環境を実際に戦わせ、初手が倒れて2枠目が出た直後の盤面を保存する。
5. 保存盤面へ2枠目候補を1体ずつ差し替えて再戦する。
6. 一次上位から2枠目環境を更新し、別の保存盤面で全候補を再評価する。

同じ1試合だけを見るのではなく、異なる味方・敵・属性・HP残量・交代時刻を持つ多数の盤面に対する結果を集計する。

現時点の環境頻度は実戦の採用ログではなく、全候補の自己対戦評価から反復生成した予測値である。実際の対戦ログを取り込めるようになった時点で、登場頻度とスキル再現率を校正する。

## 標的と攻撃順

標的判断を1本の固定ロジックにしない。次の3方針を同数の盤面で再現する。

- 残数平準化: 敵の残りキャラ数が多いプレイヤーを最優先し、残数差を縮める。
- 撃破確定: その攻撃で倒せる相手を最優先し、その中で残数差を縮める。
- スキル脅威: 残数差を優先した上で、スキル発動が近い相手を先に倒す。

各方針では、味方・敵とも推定ダメージの高いキャラから攻撃する。これは実戦の「残数を揃える」「倒せる初手を確実に倒す」「発動前の敵を狙う」「基本は火力順」という判断を、単一の決め打ちにせず感度分析するためである。

設計根拠: [英語物語 攻略Wikiの対戦イベント](https://wikiwiki.jp/engstory/%E5%AF%BE%E6%88%A6%E3%82%A4%E3%83%99%E3%83%B3%E3%83%88)、[対戦の思考書き殴り②](https://note.com/context_eigo/n/n9daac6a204f9)

## 攻撃評価

- 同じ枠にいる環境敵が、そのターンに倒されて次へ交代した割合。
- 環境敵を種類ごとに集計したマクロ撃破率。
- 50%以上の盤面で対処できた敵キャラクター種類数。
- 本人が直接倒した数。
- 同じHP・Power・属性でスキルだけを外した場合と比べ、チーム全体で増えた撃破数。

全体攻撃バフは、バフ倍率そのものではなく、実際に味方5人の攻撃へ適用した結果として敵の交代が増えた場合に評価される。

## 防御評価

- ターン開始時にいた味方が、交代せず残った割合。
- 評価対象本人が交代せず残った割合。
- スキルなし比較と比べて防いだ味方交代数。

シールド・かばう・回復・蘇生は、倍率ではなく実際に味方の交代を防げた場合に評価される。

## スキル再現性

枠番号から80%などの固定補正は行わない。

前枠を実際に戦わせ、2枠目が登場した時点の`skillCounter`を保存する。候補のスキルは、その保存値が必要ターン以上の盤面でだけ発動できる。したがって、2枠目のスキルターン2は初手が1ターン以上生存した後に倒れた盤面でしか評価されない。集計結果には全体率だけでなく、2枠目の登場ターン別・標的方針別の使用可能率も残す。

## 順位

- 攻撃順位: 同枠敵撃破率を第一基準にする。
- 防御順位: 味方維持率を第一基準にする。
- 総合順位: 1ターン後の敵交代数が味方交代数以上だった盤面率を第一基準にする。

異なる指標を任意の40%・35%・25%で合算しない。攻撃・防御・総合を分けて出力する。
