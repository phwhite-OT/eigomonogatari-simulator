# キャラクター先行評価 v1

## 目的

ランダムに5体を組んでから採点する前に、縛りと枠ごとに各キャラクターを評価する。最初の生成対象は「火・水・風をすべて許可した2枠目」である。

## 属性縛り

- キャラクター自身の属性は、火・水・風・火水・火風・水風・全の7通り。
- 縛り入力は火・水・風の3項目。
- 選択した色を1色でも含むキャラクターを対象にする。たとえば火を選ぶと、火・火水・火風・全が候補になる。

## 枠の条件

- 1枠目はスキルターンによる除外をしない。
- 2枠目以降は、想定ターンと同じかプラス1のキャラクターだけを対象にする。
- 2枠目ならスキルターン1または2、3枠目なら2または3となる。
- 短縮と遅延はスキル効果を0点として扱うが、キャラクター自体は除外しない。

## 基礎性能点

同じ縛り・同じ枠の全候補と総当たりで最低保証ダメージを計算する。

- 攻撃点40%: 撃破率と相手HPに対するダメージ率。
- 耐久点35%: 生存率と攻撃後の残HP率。
- スキル点25%: 対象数、倍率、継続ターン、属性条件、使用可能になる早さを「1人分の行動価値」に換算した相対順位。

各成分は同じ縛り・同じ枠の候補内で0～100の相対点にする。したがって、別の縛りや枠の点数をそのまま横比較しない。

## 連続コスト評価

低コスト・中コスト・高コストという固定境界は作らない。

1. 5枠それぞれの基礎性能点から、総コスト上限ごとの最良静的デッキを作る。
2. 総コストを1増やしたときに最良デッキがどれだけ強くなるかを、前後8コストで平滑化して「コスト1点の価値」にする。
3. 各キャラクターについて `基礎性能点 - コスト × コスト1点の価値` を計算する。
4. 総コストを1刻みで動かし、縛り・枠ごとの順位変化を記録する。

コスト上限が厳しい間は安くて効率のよいキャラクターが上がり、余裕が増えるにつれて高コストの高性能キャラクターが自然に上がる。固定された境界で急に環境を切り替えない。

## 現段階の限界

- これは候補を絞るための一次評価であり、完成デッキの相乗効果はまだ含めない。
- スキル価値は説明可能な共通換算式による暫定値。次段階で実際の5対5盤面シミュレーションと比較して補正する。
- 静的デッキ限界は同一キャラを重複させずに計算するが、最終的な推薦は従来どおりデッキ検証を通す。

## 実行方法

```powershell
npm run rate:characters
```

初期値は全3色、2枠目、総コスト150。変更例:

```powershell
node scripts/rate-characters.mjs --position=2 --cost=120 --attributes=fire,water
```

結果は `reports/character-ratings/` 以下にJSONとExcelで開けるCSVで出力する。
