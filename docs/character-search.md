# キャラクター検索

「キャラ検索」タブでは、収録キャラをキーワードで横断検索できます。検索はブラウザ内で完結し、入力内容を外部へ送信しません。

## 使い方

検索欄に、探したい言葉を空白で区切って入力します。複数のキーワードを入れたときは、すべてに合うキャラだけを表示します。

- 火 全体攻撃
- 水 回復
- かばう
- 関東 R
- 浅子
- 低コスト 全体攻撃

火・水・風・火水・火風・水風・全の属性と、全体攻撃、連続攻撃、回復、蘇生、かばう、防御、短縮、遅延、属性変更、攻撃力アップは、スキル種別として検索できます。それ以外の名前、地域、レアリティ、スキル説明、ID、ステータス値は文字列として探します。

低コスト、高火力、高HP、スキル早いは候補を除外せず、表示順だけに反映します。名前は軽い誤字なら近い候補を出します。

## 再利用

結果カードではIDをコピーでき、対戦の必須へと最軽装候補へで既存フォームへ追加できます。JSONを読み込んだときは検索対象も同じデータへ更新されます。

ブラウザのコンソールなどからは EigoDeckApp.createCharacterSearchIndex と EigoDeckApp.searchCharacters を利用できます。
