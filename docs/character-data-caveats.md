# Character data caveats

このファイルは、Wiki内の記載矛盾・表記差・誤記疑いがあり、現時点では**暫定値/暫定表記で運用しているキャラクター**を記録する恒久メモです。

## 運用ルール

- ここに載っているキャラは削除しない。デッキ生成・評価では現在値を使ってよい。
- ただし「確定データ」とは扱わない。
- Wikiや一次情報で矛盾が解消したら、`src/data/character-supplements-2026.js` とこのファイルを同時に更新する。
- 名前や数値を推測だけで勝手に書き換えない。差異を見つけた場合はまずここへ記録する。
- 調査時は英語物語Wikiを基準にする。Wiki内部で矛盾する場合のみ「暫定」として保持する。
