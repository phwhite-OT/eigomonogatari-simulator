# 手入力キャラの追加

対戦デッキタブの「＋ キャラを追加」から、新しいキャラを登録できます。追加したキャラには自動IDが付き、対戦デッキ探索・キャラ検索・最軽装のすべてで同じデータを使います。データはこのブラウザに保存され、ページを再読み込みしても残ります。

## ステータスの登録

手入力では **無凸Lv1のHP・Power** を入力し、育成状態を選びます。

| 段階 | 使用する値 |
| --- | --- |
| 梅 | Lv1の実数値（Excel収録キャラは竹値の半分） |
| 竹（無凸LvMAX） | Lv1の2倍 |
| 松（完凸LvMAX） | レア度ごとの最大Lvから算出。例外は個別実数値を登録 |

標準の完凸上限は、N: Lv30→54、R: Lv50→100、CR: Lv60→132、ZR/MZR/伝: Lv99→237です。完凸に共通の固定倍率はありません。

標準上限と異なるキャラは、「竹HP・Power」と「松HP・Power」へ、ゲーム内または図鑑で確認した実数値を入力してください。入力した実数値を最優先します。

Excel収録キャラは、Book1.xlsxの竹値（F/G列）と松値（J/K列）をそのまま使います。ExcelにはLv1値がないため、最軽装の梅は竹値を半分にして使います。竹は無凸LvMAX、松は最大限界突破LvMAXを使用します。

## スキル詳細

スキルの種類、ターン、名前、対象に加え、詳細設定で倍率・ヒット数・継続ターン・効果量・対象人数・味方属性・敵属性・属性変更先を登録できます。

短縮と遅延も入力・保存できます。対戦デッキの環境評価では効果を除外しますが、キャラ自身は初手を含む候補に残ります。最軽装の完全探索では、短縮・遅延の効果も処理します。

## 注意

- 同名でも属性・ステータス・スキルが異なる場合は別キャラとして登録されます。
- 同名・同ステータス・同スキルの完全重複は、読み込み時に統合されます。
- 複数の独立効果などフォームで表せない特殊スキルは、JSON読み込みを使用してください。
